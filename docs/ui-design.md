## 1. 系统链路（UI 的设计前提）

```
BLE 广播/扫描 → GATT 握手(网络状态/IP/指纹/PIN/root能力)
     │
     ▼
同网判定(子网 + TCP 实测) ── 同网 ──► LocalSend 直连(IP 直连，跳过组播)
     │
     └── 异网 ──► 热点方开热点 ──► 对端接入 ──► LocalSend 传输(53317)
                    (root 真热点 / 非 root LocalOnlyHotspot)
失败兜底：每个系统环节保留手动入口
```

- 蓝牙握手同步交换 LocalSend 证书 SHA-256 指纹与 PIN → 组网完成后免 mDNS 直连、免证书信任弹窗
- root 能力参与角色协商：优先让 root 方当热点方（真热点带外网）；双端 root 全静默

## 2. 权限矩阵（按版本）

| 能力 | Android 8–11 | Android 12+ | Android 13+ |
|---|---|---|---|
| BLE 广播/扫描/GATT | `ACCESS_FINE_LOCATION` | + `BLUETOOTH_SCAN`(**neverForLocation**)/CONNECT/ADVERTISE | 同左 |
| 开 LocalOnlyHotspot | `ACCESS_FINE_LOCATION` | 同左 | `NEARBY_WIFI_DEVICES`(neverForLocation) |
| 连接热点 | 8–9: `WRITE_SETTINGS`+`addNetwork`；10–11: `WifiNetworkSpecifier` | 同 10–11 | `NEARBY_WIFI_DEVICES` |
| 文件 | 8–10: `READ/WRITE_EXTERNAL_STORAGE` | 11+: `MANAGE_EXTERNAL_STORAGE`(特殊权限) | 同左 |
| 网络状态 | `ACCESS_NETWORK_STATE/ACCESS_WIFI_STATE/CHANGE_WIFI_STATE` | 同左 | 同左 |

Root 模式可越过多数权限（`pm grant` / `appops set` / shell uid 自带系统权限）。

## 3. 信息架构

**单页流式主页面 + 侧滑抽屉**（无底部导航）。

- 主页面 = 附近/任务流式 Feed（唯一主战场）
- 抽屉 = 全部二级入口：共享开关、传输记录、文件浏览器、设置、权限总览、Root 命令审计日志、关于

## 4. 页面规格

### 4.1 主页面（两态左右布局 · 2026-09-02 定稿）

- **开屏（配对前）**：顶部分两栏——左「本端设备卡」占 **1/3 宽度**；右「对端扫描列表」占 2/3（上下滑动；支持清除失效设备）。下方：流程动画区 + **时间流**（事件时间线，上下滚动）。
- **配对/组网后**：顶部分两栏等宽——左本端恢复 **1/2 宽度**；右「对端设备卡」（含**重新扫描 / 接入 / 未连接**状态与组网按钮）。宽度切换带 **Compose 动画过渡**；配对与组网过程显示流程动画。
- 导航：抽屉状态驱动切页（轻量，无 Navigation-Compose）。默认开屏即本页。风格：Material3 + 深色跟随系统（不新增主题定制）。

#### 颜色区（顶部 ~1/8 高）
- **左 1/6（色系入口）**：窄条展示当前色系（色块 + 名称/图标）；**点开后向右展开**色系列表（红/橙/黄/绿/青/蓝/紫/品/粉/棕/灰/白/黑…，横向滑动 chips，覆盖在右侧区域上层）；选中色系后面板收拢，右区切换为该色系取色
- **右 5/6（具体颜色）**：当前色系下的具体颜色（该色系深浅/明暗连续渐变格，如 HSV 同 hue 变 value/saturation 的 8-12 格），**可左右滑动**，点选即选中
- 中间**竖分割线**分隔，**左右宽度比固定 1:5**
- 选中后即时在页面内预览（当前选中色 chip/描边显示）；**保存才写入并应用主题强调色**
- API27+「从壁纸取色」入口保留在颜色区（入口按版本隐藏，API26 无）；取到的壁纸主色同样先入选中态、保存生效

#### 壁纸区（场景三按钮 + 复用预览区）
- 顶部三按钮切换**场景槽**：统一壁纸（兜底）/ 深色模式壁纸 / 浅色模式壁纸（语义同 v0.5.7 WallpaperStore 三槽）
- 下方**复用区域**：渲染当前场景槽的壁纸预览（壁纸图 + 当前遮罩叠加，与主页面背景同一渲染函数）；槽未设 → 占位提示「点击选择壁纸」
- **点击预览区** → 弹出三选项：`跟随系统壁纸` / `自选图片（SAF）` / `清除`（清除仅在已设时可选）
- SAF 选图后需 `takePersistableUriPermission(READ)`（修 v0.5.7 未持久授权导致重启失效问题，失败 try/catch 不崩溃）；uri 存字符串、预解码缩略/预览图（复用现有手写 decode：bounds 预读 + inSampleSize + 长边收边，上限 预览 720px / 缩略 480px，无 coil）

#### 遮罩区（底部固定 · 全局共用）
- 文字 + Slider 0–80%（显示百分比），拖动即页内预览（复用区与背景遮罩同步变）；保存后生效

#### 保存语义（v0.5.8 新交互）
- 页面持**本地编辑态**：三槽（type/uri）、maskAlpha、强调色、当前场景——进入页面时从 prefs 载入，任何改动只改本地态并即时页内预览
- 右上角**保存**：一次性写入 prefs（三槽 + mask + accent）→ `wallpaperTick++` → 主页面背景刷新 + **强调色应用到主题** → Snackbar「已保存」；离开页面未保存 = 丢弃（首版不做未保存提示）
- 保存前改动不影响主页面背景（主页面背景只在保存后变化）

#### 主页面浮层化（修「背景不变」）
- HOME 主页面内容容器（两态左右卡片 / 时间流区域 / 顶栏）改为**半透明表面**（如 surfaceContainer/background alpha ≈ 0.88–0.92，具体以文字可读为准）浮于壁纸之上，壁纸铺满整窗——背景真实可见；可读性由遮罩 + 表面半透明层承担
- 抽屉 / LOG / 设置 / 关于页保持不透明 M3 表面（壁纸只垫主页面）
- 无壁纸（三槽全空）时回纯色现状，浮层化不产生影响

#### 强调色应用（v0.5.8 起）
- 保存的强调色应用到 **App 主题强调色**（primary 系列派生：按钮/选中态/滑钮等随色变）；未选时用 M3 默认
- 深浅模式仍跟随系统（**全局深浅切换留 UI1b-C**，本版不做手动切换）
- 主题需支持运行态换强调色：App 根层持强调色 state（初值读 prefs），保存后更新触发 MaterialTheme 重算

```
┌─────────────────────────────┐

│                             │

```

规则：
- 三泳道：握手（开关态）→ 组网（开关态）→ 传输（进度条），分块渲染
- 角色协商结果**先展示后执行**：「本机将被指定为热点方(root 真热点)」，避免突然断 Wi-Fi 的惊吓
- 热点开启导致本机 Wi-Fi 断开时：泳道下方黄条提示「热点共享中，本机 Wi-Fi 已断，蜂窝网络不受影响，传输结束后自动恢复」
- 任何系统弹窗出现前 App 先亮提示卡（什么弹窗/点哪个按钮/谁在等）；误关后提供「重试」
- 失败自动降级并在泳道右侧给出原因（如「对方无 root → 改用系统弹窗引导」），不静默切换
- 右上角 ⚙ 入口直达 Root 命令审计日志

## 7. Root 增强（可选）命令矩阵

| 能力 | Android 8–9 | Android 10–11 | Android 12+/13+ |
|---|---|---|---|
| 开热点 | 反射 `setWifiApEnabled` + `svc wifi enable` | `cmd wifi start-softap` | `cmd wifi start-softap` / `cmd hotspot start` |
| 配热点 | 写 `/data/misc/wifi/...` 或隐藏 API | `cmd wifi set-softap-config <ssid> <pass>` | 同左 |
| 连热点 | **LocalSocket 直连 `@android:wpa_wlan0`**（已实测可行，无 wpa_cli 二进制也可控）/ 改 `WifiConfigStore.xml` + 重启 wifi | `cmd wifi connect-network` | 同左 |
| 静默授权 | `appops set <pkg> android:write_settings allow` | 同左 | 同左 |
| 常驻可发现 | 反射 `BluetoothAdapter.setScanMode(DISCOVERABLE)` | 同左 | 同左 |

- 探测：`su -c id` 校验 `uid=0`；兼容 Magisk `su -c` / `su 0 -c`
- 原则：root 只消灭系统交互，不做 root-only 功能；命令白名单 + 审计日志
- **待验证项**：`cmd wifi` 系列在 10/11 的具体可用性——实现前真机实测

### 7.1 已验证 · 荣耀 8 / FRD-AL10 / Android 8.0.0 (SDK 26) / Magisk（2026-09-01）

| 项 | 结果 |
|---|---|
| `su -c id` | ✅ `uid=0(root)` `context=u:r:magisk:s0`，Magisk root 可用 |
| `wpa_cli` 二进制 | ❌ 不存在（`/system/bin`、`/system/xbin` 均无）——**ROM 未带** |
| `cmd wifi` | ❌ `No shell command implementation`——8.0 无该子命令实现 |
| `cmd bluetooth_manager` | ❌ 同上，8.0 无 |
| `svc` | ✅ `/system/bin/svc` 存在（`svc wifi` / `svc bluetooth` 可用） |
| `/data/misc/wifi/` | ✅ root 可读写：`WifiConfigStore.xml`、`softap.conf`（SSID+密码明文，实测含 "Xiaomi 12s" 字样）、`hostapd/`、`sockets/`(wlan0, p2p-dev-wlan0) |
| wpa_supplicant | 运行中：`/vendor/bin/hw/wpa_supplicant -O/data/misc/wifi/sockets -g@android:wpa_wlan0`——**控制口抽象 socket `@android:wpa_wlan0`** |
| Magisk | ✅ block/busybox/config/mirror/modules 齐全 |

**8.0 root 结论**：
- 8.0 无 `cmd wifi`/`cmd bluetooth_manager` shell 快路径，热点与连网只能走**反射 hidden API** 或**直控底层**两条路
- 连热点推荐 **LocalSocket 直连 `@android:wpa_wlan0`**（Android `LocalSocket` 即可连，无需 wpa_cli 二进制，走 Ctrl_Interface 协议 ADD_NETWORK/SET_NETWORK/ENABLE_NETWORK）——此路径已在设备上确认目标 socket 存在且 root 可连
- 备选：改 `WifiConfigStore.xml`（写 SSID+PSK）后重启 wifi；开热点：反射 `setWifiApEnabled`（有 CHANGE_WIFI_STATE 即可）或改 `softap.conf` + `svc wifi` 重启

### 7.2 真机排障 · 2026-09-01（两台 Android 12+）

- **现象**：双机 App 均广播成功（状态卡无错误红字），扫描列表为空，无扫描异常提示
- **根因**：`BLUETOOTH_SCAN` 未声明 `usesPermissionFlags="neverForLocation"` → Android 12+ 将扫描结果视为位置数据，应用未授定位权限时**静默不投递**（`startScan` 成功、无回调、无错误；广播走 ADVERTISE 权限不受影响）
- **修复（v0.1.1）**：Manifest `BLUETOOTH_SCAN` 加 `neverForLocation`；`BleScanner.onScanResult` 增加 `Log.i`（device/rs ssi）供诊断
- **影响面**：8–11 机型仍需 `ACCESS_FINE_LOCATION`；12+ 不再要求定位
- **验证状态**：v0.1.1 待双机重测
